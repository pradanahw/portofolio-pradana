// talenta teknik

Talenta Teknik — Sistem Manajemen Toko AC

Aplikasi web internal untuk mendigitalkan operasional harian toko AC keluarga sendiri — menggantikan pencatatan manual (buku/Excel) dengan sistem yang bisa diakses dan diperbarui bersama secara real-time dari HP maupun laptop, oleh pemilik toko dan teknisi lapangan.

HTML / CSS / JS (Vanilla) Supabase (PostgreSQL) Vercel Mobile-first Real-time sync
// latar belakang

Tentang Proyek

Toko sebelumnya mencatat stok AC, harga, dan jadwal kunjungan servis secara manual, yang rawan selisih data ketika lebih dari satu orang (pemilik dan teknisi) perlu mencatat atau mengecek informasi yang sama di waktu berbeda.

Proyek ini dibuat untuk menyatukan seluruh pencatatan ke satu sistem yang selalu sinkron, ringan, dan mudah dipakai tanpa perlu pelatihan khusus — mengingat pengguna akhirnya adalah pemilik toko dan teknisi lapangan yang non-teknis.

// fitur utama

Fitur

Manajemen Inventaris AC

Pencatatan tipe, brand, kapasitas (PK), harga, dan stok unit, lengkap dengan indikator visual saat stok menipis, serta pencarian dan filter berdasarkan kategori.

Jadwal Servis Teknisi

Pencatatan kunjungan servis (pelanggan, alamat, jenis layanan, teknisi yang ditugaskan, tanggal & jam), dengan tombol cepat menandai status "Selesai" tanpa buka form edit.

Status Pembayaran

Penanda Lunas / Belum Dibayar per jadwal servis, membantu tracking piutang pelanggan.

Dashboard Ringkasan

Statistik otomatis: jumlah tipe AC, total unit stok, estimasi nilai stok, servis 7 hari ke depan, servis selesai minggu berjalan, dan transaksi belum dibayar.

Catatan Bebas

Ruang catatan internal untuk hal-hal yang tidak masuk kategori data terstruktur — pengingat, pesan pelanggan, dan lainnya.

Multi-device, Real-time Sync

Data yang diisi di satu perangkat otomatis muncul di perangkat lain dalam hitungan detik, tanpa perlu refresh manual.

// arsitektur & teknologi

Cara Kerja

Frontend

HTML, CSS, JS Vanilla — dirancang mobile-first agar nyaman dipakai di layar kecil.

Hosting

Vercel — menyajikan file tampilan aplikasi ke pengguna.

Database

Supabase (PostgreSQL) — menyimpan seluruh data toko, diakses langsung dari browser via Supabase JS Client.

1

Pengguna membuka link aplikasi di browser (HP/laptop) — Vercel mengirimkan file tampilan.

2

Begitu halaman dimuat, aplikasi langsung menghubungi Supabase untuk mengambil data terbaru (stok AC, jadwal servis, catatan).

3

Saat pengguna menambah/mengubah data, perubahan langsung dikirim dan disimpan ke Supabase.

4

Perangkat lain yang membuka aplikasi yang sama otomatis mendapat data terbaru pada pengecekan berikutnya (polling setiap 12 detik).

// cara menggunakan

Cara Menggunakan

1

Buka link aplikasi di browser.

2

Pilih salah satu dari 4 tab: Inventaris AC, Jadwal Servis, Ringkasan, atau Catatan.

3

Tekan tombol "+" di pojok kanan bawah untuk menambah data baru sesuai tab yang sedang dibuka.

4

Gunakan kolom pencarian dan filter di bagian atas untuk menemukan data dengan cepat.

5

Pada Jadwal Servis, tekan tombol "Tandai Selesai" atau "Tandai Lunas" untuk update status tanpa harus membuka form edit.

// tantangan & pembelajaran
Tantangan: merancang sistem penyimpanan data bersama (shared state) yang tetap ringan tanpa sistem login yang rumit, mengingat pengguna akhir non-teknis (ibu pemilik toko dan teknisi lapangan); menyeimbangkan kemudahan akses (tanpa login) dengan kebutuhan keamanan dasar data toko; dan mengiterasi UI berdasarkan masukan langsung dari calon pengguna — misalnya format jam 24 jam agar tidak membingungkan, serta urutan data otomatis dari yang terbaru.

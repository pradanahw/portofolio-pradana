Notee

Notes App dengan Sentuhan Browser Modern — aplikasi pencatat pribadi berbasis web (single-page, single HTML file), dirancang ulang dari versi personal menjadi versi publikasi yang lebih elegan dan siap ditampilkan di portofolio. Semua data tersimpan langsung di browser pengguna, tanpa backend maupun database.

HTML / CSS / JS localStorage Google Calendar Embed No backend

// latar belakang

Tentang Proyek

Awalnya aplikasi ini dibuat sebagai catatan personal dengan tampilan playful. Untuk kebutuhan portofolio, versi ini dibangun ulang dengan pendekatan desain yang lebih profesional, mengambil inspirasi dari estetika browser modern (Comet) — bersih, minim gangguan visual, tapi tetap terasa hidup lewat micro-interaction.

// fitur utama

Fitur

Catatan (Notes)

Tulis, edit judul & isi, pin catatan penting, beri label warna, cari, dan urutkan berdasarkan waktu.

To-do List

Tambah, tandai selesai, edit, dan hapus tugas harian.

Riwayat / Trash

Catatan yang dihapus disimpan selama 30 hari dan bisa dipulihkan kapan saja.

Kalender

Integrasi embed Google Calendar lewat Calendar ID, plus tombol pintas untuk menambah jadwal baru.

Backup & Restore

Ekspor seluruh catatan ke file JSON, dan impor kembali kapan pun dibutuhkan.

Tanpa Server

100% berjalan di sisi klien — data privat dan tersimpan lokal di perangkat pengguna.

// pendekatan desain

Desain

Konsep "Jendela Browser"

Seluruh aplikasi dibungkus dalam bentuk jendela browser (topbar dengan traffic-dot dan address bar palsu) untuk menegaskan tema "Comet browser" secara literal.

Palet Warna

Netral (putih/abu) dengan satu warna aksen biru-indigo, menggantikan tema pink-ungu yang lebih personal dari versi awal.

Tipografi

Instrument Serif untuk judul, Inter untuk isi teks, dan IBM Plex Mono untuk metadata seperti tanggal — memberi kesan presisi ala antarmuka teknis.

Micro-interaction

Animasi latar aurora yang bereaksi terhadap kursor, indikator tab yang meluncur otomatis, efek tilt 3D pada kartu catatan saat hover, dan transisi halus antar panel.

Aksesibilitas

Seluruh animasi otomatis nonaktif jika pengguna mengaktifkan pengaturan "reduced motion" di sistem operasinya.

// cara menggunakan

Cara Menggunakan

Buka aplikasi langsung lewat my-notee.vercel.app, atau jalankan file HTML-nya langsung di browser.

Tab "Catatan" — klik tombol bulat biru (+) di kanan bawah untuk menulis catatan baru; klik ikon expand untuk membuka tampilan penuh.

Tab "To-do" — ketik tugas lalu tekan Enter atau klik "Tambah".

Tab "Riwayat" — lihat dan pulihkan catatan yang sudah dihapus (tersimpan 30 hari).

Tab "Kalender" — masukkan Calendar ID dari akun Google Calendar untuk menampilkan jadwal.

Gunakan tombol "backup" untuk mengunduh seluruh catatan sebagai file cadangan, dan "pulihkan" untuk mengimpornya kembali.

// tantangan & solusi
Tantangan: menyeimbangkan kesan "hidup" (animasi, interaktivitas) dengan kesan "elegan dan tenang" agar tidak berlebihan atau mengganggu fungsi utama sebagai aplikasi produktivitas. Solusi: membatasi animasi pada elemen-elemen kunci saja (latar belakang, indikator tab, hover kartu) dengan durasi dan intensitas yang halus, serta tetap menghormati preferensi aksesibilitas pengguna.

// hand cipher

Hand Cipher

Interactive Hand & Face Tracking Playground — eksperimen web yang mengubah kamera laptop menjadi kanvas gestur. Melacak posisi tangan dan ekspresi wajah secara real-time langsung di browser, lalu mengubahnya menjadi visual generatif bergaya arcade retro dan mini-game puzzle foto yang dimainkan sepenuhnya dengan gestur tangan.

MediaPipe Hands MediaPipe Face Mesh HTML5 Canvas Vanilla JavaScript Single-file build
// ringkasan

Tentang Proyek

Seluruh pelacakan tangan dan wajah dijalankan menggunakan MediaPipe Hands dan MediaPipe Face Mesh dari Google, sepenuhnya di sisi klien melalui browser. Rendering visual dibangun dengan HTML5 Canvas dan JavaScript murni tanpa framework, sehingga proyek ini ringan dan bisa langsung dibuka sebagai satu file HTML.

Karena semua pemrosesan terjadi di perangkat pengguna, tidak ada video atau data wajah yang dikirim ke server manapun.

// fitur utama

Fitur

Sidik Jari Digital

Setiap gestur tangan menghasilkan kode heksadesimal unik dari koordinat 21 titik landmark tangan, berubah setiap kali bentuk tangan berubah.

Kepal untuk Memadat, Lepas untuk Menyebar

Saat tangan mengepal, partikel tertarik ke titik pusat telapak tangan membentuk gumpalan bercahaya. Melepas kepalan cepat melontarkan partikel keluar.

Interaksi Dua Tangan

Ketika kedua tangan mengepal dan didekatkan, dua gumpalan partikel saling tertarik dan sebagian partikelnya berpindah antar gumpalan.

Bangun Ruang dari Jari yang Menempel

Ujung jari yang berdekatan otomatis terhubung garis bercahaya. Tiga ujung jari atau lebih membentuk bidang transparan.

Pembacaan Ekspresi Wajah

Membaca lengkung sudut bibir relatif terhadap jarak antar mata untuk menebak ekspresi secara kasar, ditampilkan sebagai label di atas kepala.

Puzzle Foto dengan Gestur Pinch

Ambil foto diri, pilih tingkat kesulitan grid 3x3 hingga 5x5, lalu susun kembali potongan yang teracak menggunakan gestur mencubit tangan.

Tema Visual Retro Arcade

Palet warna kuning neon dan magenta, font piksel, dan efek scanline ala layar CRT untuk nuansa mesin arcade tahun delapan puluhan.

// cara menggunakan

Cara Menggunakan

1

Buka file HTML di browser, klik tombol Aktifkan Kamera, dan izinkan akses kamera saat diminta.

2

Gerakkan tangan di depan kamera untuk melihat rangka tangan, kode sidik jari digital, dan status keterbukaan tangan yang diperbarui secara langsung.

3

Kepalkan tangan perlahan agar sistem mengumpulkan partikel, lalu lepaskan kepalan secara cepat untuk melihatnya menyebar.

4

Tempelkan ujung jari satu sama lain, dalam satu tangan maupun antar dua tangan, untuk membentuk bangun ruang bercahaya.

5

Pilih tingkat kesulitan puzzle di pojok kanan bawah, klik Foto Puzzle, lalu pilih Pakai Ini atau Ambil Ulang setelah pratinjau muncul.

6

Gunakan gestur mencubit untuk memindahkan potongan puzzle hingga tersusun kembali seperti foto aslinya.
